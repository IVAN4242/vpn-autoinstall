# VPN Autoinstall

Личный VPN-сервер с панелью [3x-ui](https://github.com/MHSanaei/3x-ui) и Telegram-ботом, который сам выдаёт подключения пользователям. Одна команда превращает чистый VPS в готовый сервер: вы отвечаете на несколько вопросов, скрипт делает остальное.

## Что вы получите

- **Панель 3x-ui** со случайным адресом, логином и паролем и с настоящим сертификатом Let's Encrypt.
- **Hysteria2 по UDP:** быстрый основной протокол и запасной вариант с обфускацией salamander.
- **VLESS по TCP с маскировкой SelfSteal:** снаружи сервер выглядит как обычный сайт на вашем домене.
- **AdGuard Home:** блокирует рекламу и трекеры для всех пользователей VPN. У него своя панель на HTTPS.
- **Telegram-бота:** пользователь нажимает кнопку и получает все свои ссылки. Вы управляете доступом, сроками и лимитами прямо из чата.
- **Автоматическое обслуживание:** сертификат продлевается сам, а сервисы перезапускаются после сбоев и перезагрузок.

## Перед установкой

| Что нужно | Подробности |
|---|---|
| Сервер | **Чистый** VPS с Ubuntu 22.04+ или Debian 11+, архитектура amd64 или arm64, доступ root |
| Ресурсы | От 1 vCPU и 1 ГБ RAM, от 5 ГБ на диске |
| Домен | A-запись должна указывать на IP сервера. При Cloudflare выключите проксирование (серое облако) |
| Telegram-бот (необязательно) | Токен от [@BotFather](https://t.me/BotFather) |
| Ваш Telegram ID (для бота) | Числовой ID, его подскажет [@userinfobot](https://t.me/userinfobot) |
| Открытые порты | TCP 80, 443 и 8443, UDP 443 и 2096, а также порт панели, если у хостера есть внешний файрвол |

> Скрипт рассчитан только на чистый сервер. Если на нём уже есть 3x-ui или бот, установленные другим способом, скрипт остановится, ничего не изменив.

## Установка одной командой

Выполните от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/IVAN4242/vpn-autoinstall/main/install.sh)
```

В конце скрипт покажет адреса панелей, логины и пароли. Если вы установили бота:

1. Откройте своего бота и отправьте `/start`.
2. Выдайте себе доступ: `/admin_add <ваш_ID> <ваш_ник>`.
3. Нажмите **«🔑 Подключения»** и добавьте ссылку в приложение [Happ](https://www.happ.su/main).
4. Включите двухфакторную аутентификацию в настройках панели.

### Только 3x-ui, без бота и AdGuard

Бот и AdGuard необязательны: на вопросы об их установке ответьте `n`. Без подтверждений это выглядит так:

```bash
curl -fsSL https://raw.githubusercontent.com/IVAN4242/vpn-autoinstall/main/install.sh -o install.sh
VK_DOMAIN=vpn.example.com VK_BOT=n VK_ADGUARD=n bash install.sh --yes
```

Панель, все инбаунды, сайт, nginx и сертификат всё равно будут установлены: без них не работают TLS и SelfSteal. Клиентов вы создаёте в панели, а их ссылки копируете оттуда.

Добавить бота или AdGuard можно и позже: см. [«Добавить бота или AdGuard позже»](#добавить-бота-или-adguard-позже).

## Какие протоколы создаются

| № | Протокол | Порт | Транспорт и защита | Зачем нужен |
|---|---|---|---|---|
| 1 | **Hysteria2** | UDP 443 | QUIC, TLS, BBR | Основное подключение: высокая скорость на каналах с потерями |
| 2 | **Hysteria2 + salamander** | UDP 2096 | QUIC, TLS, обфускация пакетов | Если обычный QUIC блокируется. Можно отключить |
| 3 | **VLESS Vision** | TCP 443 | RAW, TLS, `xtls-rprx-vision` | Если UDP не работает. Выглядит как HTTPS вашего сайта |
| 4 | **VLESS XHTTP** | TCP 443 | XHTTP `stream-up`, TLS, HTTP/2 | Запасной вариант поверх HTTP/2 на том же порту. Можно отключить |

Бот выдаёт ссылки в этом же порядке и подписывает каждую.

### Как работает SelfSteal

Для маскировки используется только ваш собственный сайт на этом же сервере. Чужие домены не используются, поэтому сертификат, адрес сервера и содержимое сайта согласованы между собой.

```text
                        ┌── VLESS Vision ─────────────► интернет
Клиент ── TCP 443 ──► Xray (TLS)
                        │
                        └── всё остальное ──► nginx ──┬── сайт
                            (fallback)                │
                                                      └── секретный путь XHTTP
                                                          └──► Xray ──► интернет

Клиент ── UDP 443 / 2096 ──► Xray (Hysteria2) ────────────► интернет
```

Браузер или сканер, открывший `https://ваш-домен`, получит обычную страницу с действующим сертификатом. Скрипт предлагает на выбор три шаблона сайта. Страницу можно заменить своей: файлы лежат в `/var/www/<домен>/`.

Схема с российским мостом (двойным сервером) в этот проект не входит.

## AdGuard Home

AdGuard работает как DNS-фильтр для Xray: заблокированные домены получают адрес `0.0.0.0`, и Xray отбрасывает такой трафик. Установку можно отключить в диалоге.

```text
Запрос пользователя ──► Xray ──► AdGuard 127.0.0.1:53 ──► 1.1.1.1, 8.8.8.8, 1.0.0.1, 8.8.4.4
                          └── нет ответа за 1,5 с ──► 8.8.8.8
```

| Параметр | Значение |
|---|---|
| Панель | `https://<домен>:8443/`, логин `admin`, пароль показывается в конце установки |
| Защита панели | HTTPS, обрыв соединений по голому IP, не больше 6 попыток входа в минуту с адреса, блокировка на 15 минут после 5 неверных паролей |
| DNS | Только `127.0.0.1:53`, снаружи недоступен |
| Фильтры | AdGuard DNS filter и OISD big. Первая загрузка занимает 10–20 секунд и нагружает процессор |
| Настройки скорости | `ratelimit: 0`, режим `parallel`, таймаут 2 с, кэш 16 МБ с оптимистичным ответом, DNSSEC выключен, журнал запросов только в памяти |
| Свой домен | DNS rewrite `домен → IP сервера` |
| Память | Около 100 МБ |

Что важно знать:

- **Не включайте `ratelimit`.** Все запросы приходят с `127.0.0.1`, поэтому лимит окажется общим для всех пользователей, и VPN начнёт тормозить.
- **Сменился IP сервера?** Обновите запись в разделе «Фильтры → Перезапись DNS», иначе через VPN панели будут открываться по старому адресу.
- **Сломался сайт?** Найдите его в «Журнале запросов» и добавьте правило `@@||example.com^` в разделе «Фильтры → Пользовательские правила».
- **Реклама в YouTube остаётся:** ролики и реклама идут с одних и тех же доменов.
- В панели не видно, какой пользователь отправил запрос: все запросы приходят от Xray.

## Что спрашивает скрипт

| Вопрос | По умолчанию | Переменная |
|---|---|---|
| Домен сайта | — | `VK_DOMAIN` |
| E-mail для Let's Encrypt | не указывать | `VK_ACME_EMAIL` |
| Установить Telegram-бота | да | `VK_BOT` |
| Токен бота | — | `VK_BOT_TOKEN` |
| Telegram ID администраторов | — | `VK_ADMIN_IDS` |
| Срок доступа новых пользователей | 365 дней | `VK_NEW_USER_DAYS` |
| Шаблон и название сайта | Студия, имя из домена | `VK_SITE_CHOICE`, `VK_SITE_TITLE` |
| UDP-порт Hysteria2 | 443 | `VK_HY2_PORT` |
| UDP-порт salamander (`0` отключает) | 2096 | `VK_HY2_OBFS_PORT` |
| TCP-порт сайта и VLESS | 443 | `VK_TLS_PORT` |
| Создавать VLESS XHTTP | да | `VK_XHTTP` |
| Порт, логин и пароль панели | случайные | `VK_PANEL_PORT`, `VK_PANEL_USER`, `VK_PANEL_PASS` |
| Версия 3x-ui | v3.11.0 | `VK_XUI_VERSION` |
| Установить AdGuard Home | да | `VK_ADGUARD` |
| Порт и пароль панели AdGuard | 8443, случайный | `VK_ADGUARD_PORT`, `VK_ADGUARD_PASS` |
| Включить файрвол UFW | да | `VK_UFW` |
| Включить BBR и буферы UDP | да | `VK_TUNING` |

Ответы можно задать заранее, тогда скрипт не будет о них спрашивать. С флагом `--yes` вопросов не будет совсем:

```bash
curl -fsSL https://raw.githubusercontent.com/IVAN4242/vpn-autoinstall/main/install.sh -o install.sh
VK_DOMAIN=vpn.example.com VK_BOT_TOKEN='123456:AAE...' VK_ADMIN_IDS=123456789 bash install.sh --yes
```

По умолчанию ставится v3.11.0: на этой версии проверены все вызовы API. Вариант `latest` тоже доступен, но бот и настройка инбаундов зависят от API панели, поэтому после обновления проверьте выдачу ссылок.

## Управление ботом

Подробности — в [`bot/ADMIN.md`](bot/ADMIN.md). Основные команды:

| Команда | Что делает |
|---|---|
| `/admin_add <ID> <ник> [дней] [ГБ]` | Выдать доступ |
| `/admin_list` | Показать всех пользователей |
| `/admin_stats <ник>` | Показать статистику пользователя |
| `/admin_date <ник> <+N\|дата\|off>` | Изменить срок |
| `/admin_limit <ник> <ГБ\|0>` | Изменить лимит трафика |
| `/admin_del <ник>` | Отозвать доступ |

Бот работает только в личных сообщениях и выдаёт ссылки лишь тем, кого добавил администратор.

## Обслуживание

```bash
systemctl status x-ui vpnbot nginx AdGuardHome --no-pager   # Состояние сервисов
dig @127.0.0.1 doubleclick.net +short           # 0.0.0.0 значит, что блокировка работает
journalctl -u vpnbot -f                         # Журнал бота
ss -lntup | grep -E 'xray|nginx'                # Открытые порты
/root/.acme.sh/acme.sh --list                   # Сертификаты
```

**Обновить бота:** выполните команду установки ещё раз. Скрипт увидит предыдущую установку, обновит код бота и создаст только недостающее. Панель, пользователи, ссылки, настройки AdGuard и ваша страница сайта останутся прежними.

**Если установка прервалась:** исправьте причину и запустите команду снова. Скрипт продолжит с теми же параметрами и паролями.

### Добавить бота или AdGuard позже

Запустите команду установки ещё раз. Если компонент не установлен, скрипт предложит его добавить и спросит только нужные для него данные. Остальные ответы он возьмёт из первой установки.

Без вопросов это выглядит так:

```bash
# Добавить бота
VK_BOT=y VK_BOT_TOKEN='123456:AAE...' VK_ADMIN_IDS=123456789 bash /opt/vpn-autoinstall/install.sh --yes

# Добавить AdGuard
VK_ADGUARD=y bash /opt/vpn-autoinstall/install.sh --yes
```

Клиентов, созданных в панели раньше, бот не подхватит сам: выдайте им доступ через `/admin_add` с тем же ником, что указан в поле Email клиента. Тогда ссылки останутся прежними.

Удаляется только всё сразу: убрать один компонент повторным запуском нельзя.

### Удалить всё

```bash
bash /opt/vpn-autoinstall/uninstall.sh
```

Скрипт попросит подтвердить удаление вводом домена и сначала сохранит базу панели, пользователей и настройки в `/root/vpn-autoinstall-backup-<дата>/`.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Не выпускается сертификат | A-запись домена и доступность TCP 80 снаружи, в том числе в файрволе хостера. Проверить DNS можно на [dnschecker.org](https://dnschecker.org) |
| Hysteria2 не подключается | Открыт ли UDP-порт у хостера. Попробуйте ссылку с salamander, затем VLESS |
| Happ не показывает пинг для Hysteria2 | Обычно это не ошибка: проверяйте подключение открытием сайта |
| VPN стал медленным или перестали открываться отдельные сайты | Журнал запросов AdGuard и `systemctl status AdGuardHome`. Если AdGuard не отвечает, Xray использует 8.8.8.8 |
| Бот не отвечает | `journalctl -u vpnbot -n 50` и правильность `BOT_TOKEN` в `/etc/vpnbot.env` |
| «Панель временно недоступна» | `systemctl status x-ui` и `curl -I https://<домен>:<порт_панели>/<путь>/` на сервере |
| Администратор не видит команды | ID в `ADMIN_IDS` должен совпадать с результатом `/id`. После правки: `systemctl restart vpnbot` |
| Ни один протокол не работает | IP сервера может быть заблокирован у вашего провайдера: проверьте другую сеть или смените IP |

## Безопасность

- Токен, пароли и данные пользователей хранятся только на сервере, в файлах с доступом для root или сервиса бота. В репозиторий они не попадают.
- Бот работает от отдельного пользователя `vpnbot` с ограничениями systemd. В панель он входит по API-токену, поэтому смена пароля и 2FA его не ломают. Не удаляйте в панели токен `vpn-autoinstall`, иначе бот потеряет к ней доступ. Токен обновит повторный запуск скрипта.
- Панель доступна из интернета по HTTPS на случайном порту и секретном пути. Это не заменяет сильный пароль и 2FA. По возможности ограничьте порт своим IP.
- Не передавайте ссылки подключения посторонним: в каждой из них личный ключ доступа.
- Панель AdGuard открыта из интернета на TCP 8443 под защитой из раздела [AdGuard Home](#adguard-home). DNS и внутренний порт 3000 наружу не открываются.
- Установщик скачивает и запускает код сторонних проектов: 3x-ui, AdGuard Home (с проверкой контрольной суммы) и acme.sh. Перед использованием можно изучить `install.sh`.
