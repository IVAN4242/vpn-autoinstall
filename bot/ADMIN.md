# Инструкция администратора бота

Права администратора выдаются только по числовому Telegram ID из `ADMIN_IDS` в `/etc/vpnbot.env`. Ник в проверке не участвует. После изменения файла выполните `systemctl restart vpnbot`.

## Как устроен доступ

Доступ определяют два слоя:

1. **Список `/var/lib/vpnbot/users.json`** решает, кому бот вообще выдаёт ссылки. Сам бот в список никого не добавляет.
2. **Клиент в 3x-ui** хранит срок, лимит и трафик. Бот создаёт его при первой выдаче ссылок и привязывает ко всем включённым инбаундам Hysteria2 и VLESS.

Если человека добавили по нику, его Telegram ID привяжется при первом обращении, а вы получите уведомление. После этого чужой аккаунт с тем же ником доступа не получит.

## Команды

| Команда | Что делает |
|---|---|
| `/admin` или `/admin_help` | Краткая справка |
| `/admin_whoami` | Ваш Telegram ID |
| `/admin_list [стр]` | Все пользователи: статус, трафик, срок |
| `/admin_stats <ник\|ID>` | Подробная статистика |
| `/admin_add <ник> [дней] [ГБ]` | Выдать доступ. По умолчанию `NEW_USER_DAYS` дней и без лимита |
| `/admin_add <ID> <ник> [дней] [ГБ]` | Выдать доступ и сразу привязать Telegram ID |
| `/admin_del <ник>` | Убрать из списка и отключить клиента |
| `/admin_limit <ник> <ГБ\|0>` | Лимит трафика, `0` снимает лимит |
| `/admin_date <ник> <ДД.ММ.ГГГГ\|ГГГГ-ММ-ДД\|+N\|off>` | Срок. `+N` продлевает, `off` делает бессрочным |
| `/admin_enable <ник>`, `/admin_disable <ник>` | Включить или отключить доступ |
| `/admin_set_id <ник> <ID>`, `/admin_reset_id <ник>` | Привязать или сбросить Telegram ID |
| `/admin_repair <ник>` | Создать или привязать клиента, не меняя срок и лимит |

## Типовые ситуации

- **«У вас пока нет доступа»:** человека нет в списке. Выполните `/admin_add`.
- **Человек сменил аккаунт Telegram:** выполните `/admin_set_id`.
- **Ник заняли до первого входа:** выполните `/admin_reset_id`, затем `/admin_set_id`.
- **Нет ссылок или клиент пропал:** выполните `/admin_repair`.
- **Вы добавили новый инбаунд в панели:** бот увидит его сам. Существующих клиентов привяжет следующая выдача ссылок или `/admin_repair`.
- **Панель недоступна:** проверьте `systemctl status x-ui` и `journalctl -u vpnbot -n 50`.

Редактировать `users.json` вручную можно только при остановленном боте.
